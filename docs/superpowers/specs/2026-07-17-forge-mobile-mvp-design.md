# Forge Mobile MVP 产品与页面设计

日期：2026-07-17

## 1. 产品目标

Forge Mobile 是 Forge Desktop 的移动工作台，而不是完整桌面镜像。首版让用户离开电脑后仍能：

1. 管理并进入已授权的电脑与工作空间。
2. 创建、搜索、续接会话，并在手机与电脑间保持同一份历史。
3. 查看完整 Agent 执行过程、工具调用、命令输出、文件修改与最终回答。
4. 选择工作空间、Git 分支、Agent / Runtime、模式与模型。
5. 处理权限请求、停止运行，并在断线恢复后补齐历史。
6. 只读浏览工作空间文件、代码和 Diff。

核心体验是“口袋里的实时 Agent 工作台”：用户能清楚看到 Agent 正在哪台电脑、哪个工作空间、哪个分支上做什么。

## 2. 已确认的产品决策

- 支持多台电脑，但默认自动进入上次使用的电脑；电脑切换不占据首页主流程。
- 采用“移动工作台”信息架构，而不是纯会话优先或纯工作空间优先。
- 工作空间包含项目管理、只读文件树、文件预览和本轮变更。
- 会话保留电脑端完整执行细节，不简化为仅显示最终回答。
- 会话输入区支持切换 Git 分支、Agent / Runtime、模式和模型。
- 文件编辑、上传下载、Git 提交/合并、自动化与人才中心不进入首版。

## 3. 信息架构

底部使用四个一级入口：

1. **工作台**
   - 当前电脑与 E2EE 状态
   - 运行中任务
   - 最近会话
   - 常用工作空间
   - 新建会话、新建工作空间
2. **工作空间**
   - 工作空间列表、搜索、新建
   - 工作空间概览
   - 文件树与文件预览
   - 当前工作空间会话
3. **会话**
   - 跨工作空间会话列表
   - 搜索、工作空间筛选
   - 运行中、未读、已完成筛选
4. **设置**
   - 电脑切换与配对
   - 通知、外观、安全说明
   - 脱敏连接诊断

## 4. 页面设计

### 4.1 首次启动与配对

- 空状态只保留“扫描配对码”和“粘贴配对链接”两个动作。
- 明确显示配对码一次性、短时有效，凭证保存于系统安全存储。
- 配对完成后直接进入工作台。
- 多电脑用户在设置页管理电脑；日常从工作台顶部电脑选择器快速切换。

### 4.2 工作台

从上至下：

1. 当前电脑选择器、E2EE 连接点、重连状态。
2. 运行中任务卡：标题、工作空间、分支、阶段、耗时、当前工具、停止按钮。
3. 快捷操作：新建会话、新建工作空间。
4. 最近会话：标题、工作空间、更新时间、运行或未读状态。
5. 常用工作空间：名称、路径、在线状态。

没有运行任务时，第一卡片替换为“从哪个工作空间开始”的引导。

### 4.3 工作空间列表与详情

列表支持搜索、新建和下拉刷新。工作空间详情包含：

- **概览**：运行中任务、最近变更、最近会话。
- **文件**：只读目录树、文件搜索、代码/Markdown/TXT/JSON/YAML 预览。
- **会话**：仅当前工作空间的会话和新建入口。

文件页始终显示当前分支和“只读”标记。文件路径可复制，也可插入当前会话作为引用。

### 4.4 会话列表

- 默认按最近更新时间排序。
- 支持关键词搜索和工作空间筛选。
- 状态筛选：全部、运行中、未读、已完成。
- 卡片展示最后提问、最后回答摘要、工作空间、更新时间和运行状态。

### 4.5 会话详情

顶部显示会话标题、工作空间、连接状态和更多菜单。

时间线按轮次组织：

1. 用户提问。
2. Agent 思考与状态。
3. 工具调用和命令输出。
4. 文件修改与 Diff。
5. 最终回答。

当前步骤默认展开；已完成步骤可折叠。长命令输出默认折叠并显示摘要。Diff 卡显示文件名、增删行数和状态，点击进入全屏 Diff。

权限请求使用置顶琥珀色卡片或底部弹层，提供“拒绝”“允许一次”和协议返回的其他选项。权限卡不随时间线滚出屏幕。

### 4.6 输入区与执行上下文

输入框上方固定一行可横向滚动的上下文控制条：

- 工作空间
- Git 分支
- Agent / Runtime
- 模式
- 模型

运行开始后五项锁定，发送键变为停止方框。停止后恢复编辑。切换分支时：

- 有任务运行：禁止切换并说明原因。
- 工作区有未提交修改：显示确认提示，不静默切换。
- 切换成功：在会话时间线写入系统事件。

### 4.7 文件与 Diff

- 文件预览只读，支持代码语法着色、Markdown 渲染和长文本截断提示。
- Diff 支持“文件 / Diff”切换、增删行配色、复制路径和在会话中提及。
- 二进制文件首版只展示名称、类型和大小，不提供下载。

### 4.8 设置与诊断

- 已配对电脑列表、在线/离线状态、添加或移除电脑。
- E2EE 与本地凭证安全说明。
- 通知和深色外观。
- 连接诊断仅保留脱敏状态，不记录 Prompt、回答和凭证。

## 5. 视觉系统

- 背景：`#080B10`
- 卡片：`#10151E` / `#111923`
- 边框：`#202936` / `#293242`
- 主文字：`#F8FAFC`
- 次文字：`#788397`
- 品牌与选中态：`#8B5CF6` / `#A78BFA`
- 在线与完成：`#22C55E`
- 待确认：`#F59E0B`
- 错误与停止：`#EF4444`

紫色仅用于品牌、选中态和主要发送动作。运行状态使用绿色，权限使用琥珀色，避免整屏紫色造成层级混乱。

卡片圆角 12–16 px；触控目标不小于 44 px。中文正文使用平台原生中文字体，代码使用等宽字体。页面保持高信息密度，但通过分组标题、状态轨迹和折叠控制降低阅读负担。

## 6. 数据与协议

### 6.1 已有 RPC

- `status.get`
- `runtime.list`
- `project.list`
- `project.create`
- `session.list`
- `session.search`
- `session.messages`
- `run.start`
- `run.cancel`
- `run.subscribe`
- `permission.pending`
- `permission.respond`

### 6.2 首版新增 RPC

- `git.branches`：读取当前分支、可切换分支、detached 状态。
- `git.switch`：切换分支，运行中禁止调用。
- `workspace.files.list`：受授权根目录约束的目录列表。
- `workspace.file.read`：只读文本文件，限制大小与类型。
- `workspace.diff.list`：返回工作区或当前轮次的文件 Diff 摘要。
- `workspace.diff.get`：读取单文件统一 Diff。

所有路径 RPC 必须复用 Desktop 的真实路径校验、allowedProjects 授权和符号链接防逃逸策略。Relay 仅转发 E2EE 密文。

### 6.3 同步原则

- Daemon 会话存储是手机与电脑共同的事实来源。
- 实时事件负责低延迟展示，`session.messages` 负责首次进入和断线恢复。
- 恢复连接时按事件序号去重；运行完成后重新拉取持久化历史。
- 手机、电脑切换会话后必须得到同一轮次与最终回答。

## 7. 状态与错误处理

- 电脑离线：保留历史，只禁用运行、权限响应和分支切换。
- Relay 重连：显示非阻塞状态条，自动指数退避。
- 运行断线：重连后订阅；无法续订时拉取持久化历史。
- 权限超时：关闭权限卡并显示“请求已失效”。
- 分支冲突或工作区脏状态：显示明确原因，不自动覆盖。
- 文件过大或不支持：展示元信息和限制说明。

## 8. 首版不包含

- 文件编辑与保存
- 文件上传、下载和附件发送
- Git commit、merge、rebase、push
- 自动化管理
- 人才中心、Skill 与插件管理
- 完整 Desktop 设置镜像
- 后台持续运行与系统级推送基础设施

## 10. 验收标准

- 用户最多两次点击进入任一最近会话或常用工作空间。
- 新建会话前可选择工作空间、分支、Agent / Runtime、模式和模型。
- 运行中可看到完整过程并能停止或响应权限。
- 同一会话在手机和电脑显示相同提问、过程与最终回答。
- 断线重连后不重复、不丢失会话内容。
- 文件与 Diff 始终只读，无法越过设备授权目录。
- 多电脑切换不暴露另一台电脑的工作空间或会话。
