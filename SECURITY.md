# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed
credential. Use GitHub's private vulnerability reporting for this repository:

https://github.com/guoyang1982/forge-agent/security/advisories/new

Include affected versions, reproduction steps, impact, and any suggested
mitigation. Do not include real credentials, personal data, or confidential
third-party information in the report.

We will acknowledge a report as soon as practical and coordinate disclosure
after a fix is available. If a leaked credential is discovered, revoke or
rotate it immediately; removing it from Git history alone is not sufficient.

## Supported versions

Until the project publishes versioned releases, security fixes are applied to
the default branch only.
